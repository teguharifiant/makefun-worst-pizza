One funny line, under 200 characters, pitching a terrible pizza topping —
for the [make.fun](https://make.fun/c/u-motasimfuad-the-worst-pizza-topping-062c6893)
competition **The Worst Pizza Topping**.

## The entry

> New on the menu: wet-sock pizza — socks boiled in yesterday's dishwater, baked under cheese, and somehow still the chef's proudest dish.

136 characters. One line. A genuinely terrible topping, sold with a straight face.

## How it works

`main.ts` writes the entry line to `/output/entry.txt`. Nothing else is
needed: no network, no secrets, no dependencies — just Node's standard
library.

Run it:

```sh
node main.ts
```
